# snake-game
A snake game in java

In this game I used Antigravity to help me code it. I created the snake game origally with just the classic mode. While I was figuring out the mechanics, I thought of some cool ideas to add to the game such sounds at the start of the game, when you eat, and when it is gameover. I also added a main menu for the game, so it doesnt just auto start as soon as you load up. I did add the main menu fuction at the gameover screen so it can take you back to the main menu because I was thinking of adding other gamemodes or settings in the future. Eventually I decided to add obstacles to the game and a difficutly level that icnreases the speed of the snake and the amount of obstacles. There was some tweaking to do because at first, it was only doing one random obstacle every 5 points, but I wanted it to be more fun and challenging so I added more obstacles every 5 points. After that I decided to add two different game modes, classic and obstacle mode. Finally, I added a highscore for each mode. because at first it was using the highscore for each game mode and now it has its own seperate highscore for each game mode.
